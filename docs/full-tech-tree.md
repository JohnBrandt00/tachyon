# Tachyon Mod — Full Tech Tree & Feature Catalog

## Overview

The mod progresses from mining custom ores through industrial processing to operating a black hole reactor and beyond. Each tier introduces new machines, materials, tools, and abilities.

```
Tier 0: Mining & Smelting + Ore Crushing
Tier 1: Early Power (Thorium Reactor) + Basic Tools + Tachyon Armor
Tier 2: Particle Accelerator + Alloys + Powered Tools + Plasma Furnace
Tier 3: Condensed Light Pipeline + Advanced Gadgets + Wireless Energy
Tier 4: Singularity Engine + Exotic Matter + Antimatter + Void Mining
Tier 5: Endgame Equipment + Exotic Machines + Matter Fabrication
Tier 5+: Tachyon Dimension (stretch goal)
```

*See individual doc files in `docs/machines/`, `docs/items/`, and `docs/blocks/` for full implementation details.*
